# AI旅游助手 (AI Travel Assistant)

> 一款面向个人旅行者的AI智能旅游助手，通过对话式交互帮助用户规划行程、推荐景点、查询信息。同时作为校招AI应用开发岗位的面试展示项目，全面展示Agent工具调用、多模态理解、上下文记忆管理等AI应用开发能力。

## 核心价值

> **智能规划 + 个性化推荐**：Agent自动调用多源API为用户生成最优旅行方案，并记住用户偏好持续优化推荐。

### 11步工作流程 — 数据流转

```
  用户发送消息
       │
       │  WebSocket / HTTPS
       ▼
  ┌─────────────────────────────────────────┐
  │  Step 0: 会话初始化 (仅首次)             │
  │  ┌─────────────────────────────────────┐ │
  │  │ 初始化数据:                          │ │
  │  │ • 128K tokens 上下文窗口             │ │
  │  │ • 空的工作记忆缓冲区                 │ │
  │  │ • TokenBudget 预算计数器             │ │
  │  └─────────────────────────────────────┘ │
  └─────────────────┬───────────────────────┘
                      │
                      ▼
  ┌─────────────────────────────────────────┐
  │  Step 0.5: 加载历史 (数据流转)          │
  │  ┌─────────────────────────────────────┐ │
  │  │ ① 构造 session_key                  │ │
  │  │   = "env:session:{conversation_id}" │ │
  │  │                                        │ │
  │  │ ② CacheManager → CircuitBreaker检查  │ │
  │  │   CLOSED/HALF_OPEN → 放行            │ │
  │  │   OPEN → 跳过Redis                   │ │
  │  │                                        │ │
  │  │ ③ RedisCacheStore → Redis.GET(key)   │ │
  │  │   命中 → 返回 {messages, updated_at} │ │
  │  │   未命中 → None                       │ │
  │  │                                        │ │
  │  │ ④ 降级: PostgresCacheStore           │ │
  │  │   → MessageRepo → messages表         │ │
  │  │   → 组装 [{role, content, ...}]     │ │
  │  │                                        │ │
  │  │ ⑤ 写回缓存 (异步)                    │ │
  │  │   Redis.SETEX(key, 3600s±10%, JSON)  │ │
  │  │   → PII清洗 → TTL抖动                │ │
  │  │                                        │ │
  │  │ 产出: 消息列表 → _conversation_history│ │
  │  └─────────────────────────────────────┘ │
  └─────────────────┬───────────────────────┘
                      │
                      ▼

  │  ┌─────────────────────────────────────┐ │
  │  │ 输入: user_id                        │ │
  │  │   → MD5哈希 % 100                   │ │
  │  │   < 灰度比例 → 新版                 │ │

  │  │                                        │ │
  │  │ 如有长会话快照:                      │ │
  │  │   → 从 Redis/PG 加载 Snapshot        │ │
  │  │   → 恢复上下文状态                   │ │

  └─────────────────┬───────────────────────┘
                      │
                      ▼

                      │
                      ▼
  ┌─────────────────────────────────────────┐

  │  └─────────────────────────────────────┘ │

                      │
                      ▼
  ┌─────────────────────────────────────────┐

  │  │   → 每个chunk → 前端实时显示        │ │
  │  │                                        │ │
  │  │ ④ TracingManager 记录:              │ │
  │  │   → LLM耗时 / 首token延迟           │ │
  │  └─────────────────────────────────────┘ │
  └─────────────────┬───────────────────────┘
                      │
                      ▼
  ┌─────────────────────────────────────────┐
  │  Step 7: 上下文后置管理 (数据流转)      │
  │  ┌─────────────────────────────────────┐ │
  │  │ ContextGuard.post_process()          │ │
  │  │                                        │ │
  │  │ ① 压缩判断                          │ │
  │  │   → TokenEstimator 估算上下文 token数 │ │
  │  │   → >= 75% (128K×75%=96K) 触发压缩 │ │
  │  │                                        │ │
  │  │ ② 三层压缩策略                      │ │
  │  │   → Layer1: 保留所有 system 消息     │ │

  │  │   → (LLM 不可用时降级为计数摘要)    │ │
  │  │                                        │ │
  │  │ ③ 规则重注入                        │ │
  │  │   → 核心规则文件重新注入上下文       │ │
  │  │   → 防止压缩后 AI 行为失控         │ │
  │  │                                        │ │
  │  │ 产出: 压缩后的消息列表               │ │
  │  └─────────────────────────────────────┘ │
  └─────────────────┬───────────────────────┘
                      │
                      ▼
  ┌─────────────────────────────────────────┐
  │  Step 8: 异步记忆更新 (数据流转)        │
  │  ┌─────────────────────────────────────┐ │
  │  │ ① PreferenceExtractor               │ │
  │  │   → 分析对话内容                     │ │
  │  │   → 提取: {偏好类型, 内容, 置信度}  │ │
  │  │   → 持久化: PostgreSQL语义记忆表   │ │
  │  │   → ChromaDB 向量存储               │ │
  │  │                                        │ │
  │  │ ② MetricsCollector                  │ │
  │  │   → record_cache(CacheMetric)       │ │
  │  │   → {op, hit, latency, fallback}    │ │
  │  │                                        │ │
  │  │ ③ SnapshotManager.create_snapshot() │ │
  │  │   → 上下文状态 → JSON → Redis       │ │
  │  │   → TTL 7天 (防长会话中断)          │ │
  │  └─────────────────────────────────────┘ │
  └─────────────────┬───────────────────────┘
                      │
                      ▼
                 LLM 响应流 → WebSocket → 前端
```

### 多Agent熔断架构

```
┌─────────────────────────────────────────────────────────────────────────────────┐
│                      子Agent熔断保护机制                                          │
└─────────────────────────────────────────────────────────────────────────────────┘

  SubAgentOrchestrator
         │
         ├──→ ROUTE Agent ────→ CircuitBreaker(ROUTE)
         │                           │
         │                    CLOSED (正常)
         │                           │
         │                    连续失败5次 → OPEN (熔断)
         │                           │
         │                    60秒后 → HALF_OPEN (尝试恢复)
         │                           │
         │                    连续成功2次 → CLOSED (恢复)
         │
         ├──→ HOTEL Agent ────→ CircuitBreaker(HOTEL)
         │
         ├──→ WEATHER Agent ──→ CircuitBreaker(WEATHER)
         │
         └──→ BUDGET Agent ───→ CircuitBreaker(BUDGET)

  熔断期间 → FallbackHandler 返回降级响应
             └─ L1: 部分工具失败 → 基于已知信息回答
             └─ L2: 所有工具失败 → 旅行知识库内容
             └─ L3: 完全不可用 → 友好提示
```

## 快速开始

### 环境要求

- **Node.js**: 18.x+
- **Python**: 3.11+
- **PostgreSQL**: 14+
- **Redis**: Latest (可选)
- **API密钥**: DeepSeek

### 1. 克隆项目

```bash
git clone https://github.com/yourusername/travel-assistant.git
cd travel-assistant
```

### 2. 后端设置

```bash
cd backend

# 创建虚拟环境
python -m venv venv
source venv/bin/activate

# 安装依赖
pip install -r requirements.txt

# 配置环境变量
cp .env.example .env
# 编辑 .env 填入你的API密钥
```

### 3. 启动服务

```bash
# 后端
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000

# 前端 (另一个终端)
cd frontend
npm run dev
```

打开浏览器访问 http://localhost:3000

🎯 意图分类器架构
第1层
缓存层
• 语义相似度计算
• 余弦相似度≥0.8命中
• FIFO淘汰策略
• 最多500条记录
第2层
关键词层
• 正则匹配+权重评分
• 强/中/弱关键词
• 排除关键词惩罚
• YAML配置热更新
第3层
LLM层
• 结构化分类prompt
• 返回JSON格式
• 最多3次重试
• 最终降级chat
↓ 逐层降级，直到返回结果 ↓
💾 缓存层策略
• 用户向量相似度计算（生成用户向量用于记忆检索）
• 余弦相似度≥0.8算命中
• FIFO淘汰策略，最多500条记录
• 命中即返回结果，写入缓存
前置过滤规则：
包含图片 / 被标记为复杂 / 消息>50字符 / 包含多个复杂词 → 直接进入LLM层
🔑 关键词权重策略
• 强关键词：权重 0.5-0.7（如"天气"、"价格"）
• 中关键词：权重 0.3-0.4（如"查询"、"多少钱"）
• 弱关键词：权重 0.2-0.3（如"怎么样"、"如何"）
• 正则模式：额外+0.25分
• 排除关键词：负分惩罚（如query意图排除"想去"、"旅游"）
配置示例（YAML）：
intents:
  weather:
    keywords_strong: [天气, 温度, 下雨]
    keywords_exclude: [想去, 旅游, 行程]
📊 置信度决策表
置信度 处理方式 走向
≥ 0.8 高置信度，接受 触发语义校验 → 返回+缓存
0.5~0.8 中置信度 可触发澄清对话 → 返回+缓存
< 0.5 低置信度 不返回，记录best，继续下一策略
< 0.1 无效 返回chat，置信度0.1
🤖 LLM降级机制
• 结构化分类prompt（~150 tokens）
• 列出8种意图类型及详细说明
• 要求返回JSON：{intent, confidence, reasoning}
• 最多3次重试，每次超时30s
• 最终降级：chat意图，置信度0.3

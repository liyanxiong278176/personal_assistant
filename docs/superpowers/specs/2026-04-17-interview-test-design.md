## 二、三系统可视化内容

### 2.1 意图识别系统

| 指标 | 可视化 |
|------|--------|
| 三级分类器工作过程 | 流程图展示 Cache→Rule→LLM 链 |
| 准确率90%+ | 环形图 + 分类分布柱状图 |
| LLM调用减少60%+ | 缓存命中率实时数据 + 对比图 |

**缓存策略:**
- L1精确匹配缓存
- L2语义相似缓存
- 高频查询直接命中，减少LLM调用

### 2.2 记忆管理系统

| 指标 | 可视化 |
|------|--------|
| 三层记忆架构 | 分层示意图 + 容量指示器 |
| 记忆自动晋升 | 时间线展示晋升过程 |
| 偏好准确率88% | 提取偏好列表 + 置信度 |

**三层架构:**
- Working Memory: 工作记忆（近期消息）
- Episodic Memory: 情景记忆（当前会话）
- Semantic Memory: 语义记忆（长期偏好）

### 2.3 上下文压缩系统

| 指标 | 可视化 |
|------|--------|
| 前置清理 | 处理前后消息数对比 |
| 压缩触发 | Token使用率进度条 + 阈值线 |
| Token降低45%+ | 压缩前后Token对比图 |
| 长对话不中断 | 连续对话轮次计数器 |

**压缩机制:**
- 前置清理: TTL检查 + 软修剪 + 硬清除
- 推理时守卫: Token超限前拦截
- 后置压缩: LLM摘要 + 规则重注入
- 流式兜底: 截断过长输出

## 三、测试场景（完整7日游流程）

```
场景: 北京7日深度游完整流程

阶段1: 意图启动 (第1轮)
  用户: "我想去北京旅游"
  → 意图识别 → 记忆召回 → 生成初步方案

阶段2: 信息补充 (第2-5轮)
  目的地、日期、天数、预算、特殊需求
  → 意图识别持续工作 + 记忆层级积累

阶段3: 方案生成 (第6-15轮)
  上下文逐步增长
  → 前置清理工作
  → 逐步接近压缩阈值(75%)

阶段4: 压缩触发 (第16-20轮)
  触发压缩
  → 摘要生成
  → 规则重注入
  → Token降低

阶段5: 长对话验证 (第21-30轮)
  验证不中断
  → 验证记忆晋升
  → 最终指标汇总
```

## 四、量化指标目标

| 指标 | 目标值 | 测试方法 |
|------|--------|----------|
| 意图分类准确率 | ≥90% | 100条测试集验证 |
| LLM调用减少 | ≥60% | 缓存命中率统计 |
| Token成本降低 | ≥45% | 压缩前后对比 |
| 偏好记忆准确率 | ≥88% | 记忆提取验证 |
| 长对话不中断 | 30+轮 | 连续对话测试 |
